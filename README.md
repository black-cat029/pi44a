# Тесто — пиццерия

Каталог пиццерии на Next.js с SQLite и Drizzle ORM. Сохранены исходное оформление, категории, пагинация и корзина. Данные каталога читаются из базы, а пиццы можно добавлять и удалять через раздел «Управление меню».

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Сайт откроется по адресу [http://localhost:8080](http://localhost:8080). При запуске база `data/pizzeria.db` создаётся и наполняется 27 начальными пиццами. Повторный запуск заполнения через `npm run db:seed` обновляет начальные записи, не удаляя добавленные вручную пиццы.

Чтобы добавить пиццу, откройте каталог, нажмите «Управление меню» и заполните форму. Фото загружается в формате JPG, PNG или WebP и сохраняется вместе с данными в локальном каталоге. Для удаления включите управление меню и нажмите «Удалить» на карточке. Названия и изображения в базе должны быть уникальными.

## База данных и сборка

- SQLite-файл: `data/pizzeria.db`.
- Загруженные фотографии: `public/pizzas/uploads/`.
- `npm run build` собирает Next.js-приложение для Node.js-сервера; `npm start` запускает его.
- При развёртывании используйте сервер с постоянным доступом на чтение и запись к `data/` и `public/pizzas/uploads/`. Делайте резервные копии этих каталогов.
- GitHub Pages не подходит для этой версии: статический хостинг не запускает API и не может сохранять изменения в SQLite. Workflow статической публикации отключён.

Фотографии начальных товаров хранятся локально в `public/pizzas/`; авторы, лицензии и источники записаны в [image-credits.json](./data/image-credits.json).

## Стек

- Next.js App Router, React и API routes
- SQLite, `better-sqlite3` и Drizzle ORM
- Tailwind CSS; `cn`-утилита совместимости с компонентами shadcn/ui
- Lucide React

На странице показывается 4 товара. Начальные 27 позиций дают 7 страниц каталога; фильтрация по категориям сохраняется при переходах между страницами.

> Перед публикацией сервера в интернете добавьте аутентификацию для управления меню: API добавления и удаления предназначен для учебного локального приложения.
