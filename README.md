# Тесто — пиццерия

Каталог пиццерии на Next.js с SQLite-базой на Drizzle ORM, фильтрацией по категориям и серверной пагинацией. Исходное оформление сайта и корзина сохранены; стили дополнены адаптивной пагинацией.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

При запуске база `data/pizzeria.db` создаётся и наполняется 27 пиццами автоматически. Сайт откроется по адресу [http://localhost:8080](http://localhost:8080). Команда `npm run build` также подготавливает базу перед сборкой; production-сервер запускается командой `npm start`.

В VS Code можно выбрать конфигурацию **Launch Edge** или **Launch Chrome against localhost**: она запускает сервер и открывает сайт в браузере. Локальный адрес `http://localhost:8080` предназначен для разработки; он не является общедоступным HTTPS-адресом.

## Публикация в интернете

Для общедоступного сайта с HTTPS импортируйте репозиторий в Vercel. Перед production-сборкой скрипт `prebuild` заполняет SQLite-базу, а конфигурация Next.js включает файл каталога в серверный маршрут. В production база открывается только для чтения, как необходимо для файловой системы Vercel. Vercel выдаёт сайту HTTPS-адрес и может автоматически обновлять его при новых изменениях GitHub. GitHub Pages не подходит для этого проекта: он не выполняет серверный код Next.js и запросы к Drizzle/SQLite.

## Стек

- Next.js App Router и React
- SQLite и Drizzle ORM
- Tailwind CSS; `cn`-утилита совместимости с компонентами shadcn/ui
- Lucide React

Размер страницы — 4 товара. Всего в базе 27 позиций, поэтому в общем каталоге отображается 7 страниц. Категории фильтруются отдельно, а пагинация сохраняет выбранную категорию.

Для повторного заполнения базы выполните `npm run db:seed`.
