# Тесто — пиццерия

Статический каталог пиццерии на Next.js, опубликованный на GitHub Pages: [https://black-cat029.github.io/pi44a/](https://black-cat029.github.io/pi44a/). Сохранены исходное оформление, категории, пагинация и корзина.

## Запуск и сборка

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Локальная версия откроется по адресу [http://localhost:8080](http://localhost:8080). При сборке команда `npm run db:seed` обновляет 27 начальных пицц в SQLite; затем Next.js экспортирует каталог в папку `out/`. Категории и страницы фильтруются в браузере.

## Публикация

Каждое изменение в ветке `main` запускает GitHub Actions: workflow собирает статический сайт и публикует его на GitHub Pages. Для ручной сборки установите переменную окружения `GITHUB_PAGES=true` и запустите `npm run build`.

GitHub Pages не запускает серверный код и не поддерживает постоянную SQLite-базу или API. Поэтому меню сайта нельзя редактировать через браузер: изменения начальных пицц задаются в `db/seed.js` и публикуются вместе с сайтом.

Фотографии товаров находятся в `public/pizzas/`; авторы, лицензии и источники перечислены в [image-credits.json](./data/image-credits.json).
