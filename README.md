# Тесто — пиццерия

Каталог пиццерии на Next.js с SQLite-базой на Drizzle ORM, фильтрацией по категориям и пагинацией. Исходное оформление сайта и корзина сохранены; карточки всех пицц используют собственные изображения одинакового размера.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

При запуске база `data/pizzeria.db` создаётся и наполняется 27 пиццами автоматически. Сайт откроется по адресу [http://localhost:8080](http://localhost:8080). Команда `npm run build` также подготавливает SQLite-базу и создаёт статический сайт в папке `out`.

В VS Code можно выбрать конфигурацию **Launch Edge** или **Launch Chrome against localhost**: она запускает сервер и открывает сайт в браузере. Локальный адрес `http://localhost:8080` предназначен для разработки; опубликованный сайт доступен по адресу [https://black-cat029.github.io/pi44a/](https://black-cat029.github.io/pi44a/).

## Публикация на GitHub Pages

GitHub Pages раздаёт статические файлы по HTTPS и не запускает серверный код Next.js. Поэтому GitHub Actions заполняет SQLite-базу, строит статическую версию каталога и публикует её в Pages. Фотографии, категории, пагинация и корзина работают в браузере; данные каталога считываются из Drizzle/SQLite во время сборки, корзина сохраняется между страницами.

После каждого изменения ветки `main` сайт автоматически пересобирается и публикуется по адресу [https://black-cat029.github.io/pi44a/](https://black-cat029.github.io/pi44a/).

## Стек

- Next.js App Router и React
- SQLite и Drizzle ORM
- Tailwind CSS; `cn`-утилита совместимости с компонентами shadcn/ui
- Lucide React

Размер страницы — 4 товара. Всего в базе 27 позиций, поэтому в общем каталоге отображается 7 страниц. Категории фильтруются отдельно, а пагинация сохраняет выбранную категорию.

Для повторного заполнения базы выполните `npm run db:seed`.
